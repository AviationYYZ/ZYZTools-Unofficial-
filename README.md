# ZYZTools (Unofficial)

Unofficial EuroScope tools by Charlie Yablon and Elliot Potts.

Download the Preferred CYYZ PDC Settings installer from [Releases](https://github.com/AviationYYZ/ZYZTools-Unofficial-/releases/latest). Close EuroScope and TrackAudio before updating the plugin payload through the settings app.

The app checks this repository for new stable releases whenever it opens. Release tags use `vMAJOR.MINOR.PATCH` and installer assets are named `PreferredCYYZPdcPlugin-Setup.exe`.

Departure assignment starts Off. Enable Duals East or Duals West in Operations. Controller replay filtering applies to newly captured audio only.

This project is unofficial and is not affiliated with EuroScope, TrackAudio, or VATSIM.
