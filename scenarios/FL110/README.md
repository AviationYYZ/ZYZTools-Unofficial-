# FL110 Sweatboxes

These importable copies put every aircraft at 11,000 feet MSL at its scheduled spawn, including airborne departure exercises. Routes, spawn times, and any existing descent instructions are unchanged. Conflict timings and separation from the original exercises do not necessarily carry over.

Use **Import scenario** on the Sweatbox server. The four bundled west-flow defaults also use these copies on new slots; updating does not overwrite scenarios already saved on a server.
