Getting started

  1. Import a saved, resolved ZYZTools scenario into a server slot, or load the demo.
  2. Click Start. The simulator starts paused while its private internet connection is prepared.
  3. Share the connection code. In the updated ZYZTools test app, paste it in Training → Join with EuroScope.
  4. Click Run when controllers are ready. Open aircraft panel to manually command that server's aircraft.

Codes and private invites grant control of the session. Share only with trusted participants. Each slot supports up to three remote EuroScope connections. Controllers use dummy credentials with “Connect to VATSIM” unchecked.

Recovery restarts the affected scenario from the beginning, paused; it does not restore aircraft positions. Other slots continue. Automatic startup is opt-in per slot and starts paused after Windows sign-in.

Temporary Cloudflare tunnels have no uptime guarantee. Codes may change after reconnecting. This is a test build, not a guaranteed-availability hosting service.
